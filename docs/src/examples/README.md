# Examples

This chapter has examples of how to configure `chezmoi_modify_manager` for
several different programs, as well as some general examples on more advanced
topics.

* [Ignores & transforms](./basics.md) — INI basics with the keyring
  and unsorted-list transforms.
* [Advanced: set, remove, add:*](./advanced.md) — INI templating, set,
  remove, and the add:* filtering directives.
* [Plist (macOS Dock walkthrough)](./plist.md) — declarative
  management of a macOS preference plist with the plist backend.
